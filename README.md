# Dan Ross Portfolio

A custom developer portfolio designed and built with plain HTML, CSS, and
JavaScript.

The site presents selected full-stack and front-end projects, detailed case
studies, professional experience, earlier work, and information about my
approach to development and accessibility.

## Live Site

[dan-ross.dev](https://dan-ross.dev)

## Featured Work

- Real Estate Admin
- Dan Ross Portfolio
- Josephson Manufacturing

Each featured project includes a case study covering the project goals,
implementation, accessibility considerations, and results.

## Built With

- Semantic HTML
- Modern CSS
- CSS Grid and Flexbox
- Responsive typography and layouts
- Plain JavaScript
- Accessibility-focused interaction patterns

## Accessibility

The site includes semantic landmarks, structured headings, skip links, visible
focus indicators, keyboard-operable navigation, reduced-motion support, and
responsive reading order.

Automated and manual accessibility testing will continue as the site evolves.
